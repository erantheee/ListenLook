# 证书说明

这个目录里有两类文件，用途不同：

| 文件 | 谁生成 | 用途 |
|---|---|---|
| `listenlook.crt` / `listenlook.key` | **首次运行时自动生成**（用 openssl，SAN 里带本机真实局域网 IP） | 手机浏览器页面用。**不入库**（`.gitignore` 已排除） |
| `dev-fallback.crt` / `dev-fallback.key` | 手工生成，**随仓库分发** | Windows 等没有 openssl 的机器上的兜底证书 |

## 为什么要把私钥放进公开仓库

`dev-fallback.key` 是**故意公开**的，这不是事故：

- 手机浏览器读陀螺仪要求安全上下文（HTTPS），所以在 Windows 上没有 openssl 时，
  如果没有现成证书，**手机页面这条路会直接不可用**；
- 而用 Python 标准库现场生成 X.509 证书需要自己实现 RSA 和 ASN.1，代价过大；
- 所以退而求其次：随仓库带一份一次性自签证书。

**它的私钥是公开的，所以它不提供任何安全性** —— 任何拿到这份文件的人都能冒充这个
HTTPS 服务。它的唯一作用是让浏览器愿意把页面当成安全上下文加载。请只在可信局域网里用它。

想用自己生成的证书，删掉 `listenlook.crt` / `listenlook.key` 并确保本机有 `openssl`，
下次启动会自动重新生成（SAN 里会带你的真实局域网 IP，警告会少一条）。

## 手机上的警告怎么处理

自签证书必然触发浏览器的"不安全"警告（未知颁发机构）。在手机上：

- **Safari / Chrome**：点"显示详细信息" → "继续访问"。
- 如果浏览器在证书不受信的情况下**拒绝提供传感器数据**（少数版本会这样），
  就改走 app 那条路：任何能 `POST http://<电脑IP>:8421/pose` 的传感器 app 都行，
  原生 app 不受浏览器的安全上下文限制，也不需要证书。
